# Resume

Personal site and resume of Sayyid Syamil: [sayyidsyamil.github.io/resume](https://sayyidsyamil.github.io/resume)

One HTML page plus an `assets` folder. No framework, no build step. Set in Inter from Google Fonts.

## Design

- A calm page with plain sentences. The numbers sit in the margin as small notes.
- Two short demos show my own projects instead of describing them. Each plays once when it scrolls into view and has a Replay button:
  - Memoria flags a sentence that contradicts an approved decision during a meeting (an illustration with a fictional meeting).
  - Findamental reads page 5 of Maybank's FY 2025 financial statements and marks the row behind its answer (a real answer and the real page).
- Work for employers is described at a high level only: no client names, vendors, internal project names, internal metrics or system designs.
- People who turn off motion in their system settings see the finished state of each demo.
- All text is real text, so readers and AI screeners can read everything.
- Light by default. The footer button switches to dark. "Save as PDF" prints a two-page A4 CV.

## Assets

- `assets/logos`: organisation logos in full colour, from each organisation's site or Wikimedia Commons. Logos belong to their owners.
- `assets/img`: a Memoria screenshot, and a crop of page 5 of Maybank's Annual Report 2025 financial statements (public document, shown as Findamental's source).
- `og-image.png`: the 1200 x 630 link preview.

## Update

Edit the text in `index.html`, then commit and push. GitHub Pages deploys from `main`.
